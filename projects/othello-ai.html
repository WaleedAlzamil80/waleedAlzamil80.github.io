Othello agents: search, simulation, and play.

A graphical Othello implementation with human and computer players, combining heuristic search and learning-based agents.

Agents and decision methods

Minimax with alpha-beta pruning

Searches game states to a selected depth and uses a heuristic board evaluation to choose a move. Alpha-beta pruning avoids exploring branches that cannot affect the current decision.

Monte Carlo Tree Search

Evaluates candidate moves through repeated simulated games, balancing exploration and exploitation with UCB1.

Actor-Critic learning

A reinforcement-learning agent was developed for strategy learning and computer-versus-computer play.

Game interface

The Pygame interface supports human-versus-AI, AI-versus-AI, and human-versus-human play, with algorithm and difficulty settings for each player.
