Computer vision · Temporal modeling

Real-time violence detection in video.

A video-classification pipeline combining frame-level visual features with temporal modeling for violent and non-violent activity recognition.

This work was part of the Graduation Project for NTI Training's AI and IoT DEY Initiative.

Model pipeline

A pretrained MobileNetV2 extracts spatial features from video frames. A bidirectional LSTM models temporal relationships across frame sequences to classify clips.

~97%Reported accuracy
16 fpsReported throughput
VideoFrame and clip inference

Inference experiments

Two prediction modes were implemented: frame-by-frame classification and whole-video prediction using temporal information across a clip.

Evaluation limits

The reported metrics are for the dataset used in the project. Further validation is needed on standard benchmarks and more varied scenarios, including multi-person interactions, weapons, and complex crowd dynamics.
