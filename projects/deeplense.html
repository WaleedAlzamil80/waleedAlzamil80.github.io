Scientific imaging · DeepLense GSoC 2025

Learning representations of gravitational lenses.

A masked autoencoder pipeline for strong-lensing images, followed by downstream experiments in multi-class classification and super-resolution.

View project repository

Scientific question

Can a model learn useful visual representations from unlabeled strong-lensing images, and can those representations support related classification and image-reconstruction tasks?

Approach

  1. Pretrained a Vision Transformer masked autoencoder on no-substructure samples, reconstructing masked image patches with mean squared error.
  2. Fine-tuned the learned encoder for multi-class classification across no_sub, axion, and cdm image classes.
  3. Evaluated a super-resolution task using low-resolution inputs and high-resolution targets, reporting MSE, PSNR, and SSIM.

Results in the report

The classification report records approximately 97% accuracy on the reported evaluation set. For super-resolution, the report records the following final validation metrics:

29.62 dBValidation PSNR
0.9190Validation SSIM
0.002293Validation MSE

The project report notes that the reconstruction decoder was not yet well suited to super-resolution; these results are an experimental baseline, not a final architecture claim.
